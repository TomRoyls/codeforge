# no-useless-escape

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow unnecessary escape characters.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-useless-escape": "error"
  }
}
```
