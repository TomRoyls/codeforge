# no-delete-var

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow deleting variables.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-delete-var": "error"
  }
}
```
