# no-global-assign

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow assignment to native objects or read-only global variables.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-global-assign": "error"
  }
}
```
