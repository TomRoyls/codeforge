# no-import-assign

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow assignment to import bindings.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-import-assign": "error"
  }
}
```
