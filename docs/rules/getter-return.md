# getter-return

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Enforce return statements in getters.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "getter-return": "error"
  }
}
```
