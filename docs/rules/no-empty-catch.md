# no-empty-catch

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | correctness |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow empty catch clauses that may hide errors silently

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-empty-catch": "error"
  }
}
```
