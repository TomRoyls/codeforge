# no-extra-boolean-cast

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow unnecessary boolean casts.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-extra-boolean-cast": "error"
  }
}
```
