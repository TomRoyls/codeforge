# no-cond-assign

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow assignment operators in conditional expressions.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-cond-assign": "error"
  }
}
```
