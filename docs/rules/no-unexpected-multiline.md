# no-unexpected-multiline

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow confusing multiline expressions.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-unexpected-multiline": "error"
  }
}
```
