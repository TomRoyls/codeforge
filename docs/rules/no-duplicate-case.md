# no-duplicate-case

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow duplicate case labels in switch statements.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-duplicate-case": "error"
  }
}
```
