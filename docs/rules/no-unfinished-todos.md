# no-unfinished-todos

| Property | Value |
|----------|-------|
| Category | style |
| Fixable | No |
| Recommended | No |
| Deprecated | No |

## Description

Detect unfinished TODO/FIXME/HACK comments that should be addressed

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-unfinished-todos": "error"
  }
}
```
