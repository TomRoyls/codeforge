# no-var

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow the use of 'var' declarations. Use 'let' or 'const' instead.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-var": "error"
  }
}
```
