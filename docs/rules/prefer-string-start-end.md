# prefer-string-start-end

| Property | Value |
|----------|-------|
| Category | style |
| Fixable | No |
| Recommended | No |
| Deprecated | No |

## Description

Prefer template literals over string concatenation

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "prefer-string-start-end": "error"
  }
}
```
