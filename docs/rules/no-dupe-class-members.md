# no-dupe-class-members

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow duplicate class members.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-dupe-class-members": "error"
  }
}
```
