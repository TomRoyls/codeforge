# for-direction

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Enforce for loop update clause to move the counter in the right direction.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "for-direction": "error"
  }
}
```
