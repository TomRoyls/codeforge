# no-case-declarations

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow lexical declarations in switch case clauses without blocks.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-case-declarations": "error"
  }
}
```
