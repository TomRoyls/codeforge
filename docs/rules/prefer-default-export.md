# prefer-default-export

| Property | Value |
|----------|-------|
| Category | style |
| Fixable | No |
| Recommended | No |
| Deprecated | No |

## Description

Enforce using default export when a module only exports one declaration

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "prefer-default-export": "error"
  }
}
```
