# no-unsafe-call

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | security |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow unsafe calls on values that are explicitly cast as any.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-unsafe-call": "error"
  }
}
```
