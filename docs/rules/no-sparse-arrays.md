# no-sparse-arrays

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow sparse arrays.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-sparse-arrays": "error"
  }
}
```
