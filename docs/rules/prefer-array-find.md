# prefer-array-find

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | performance |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Enforce using find() method instead of filter()[0] or filter().shift() for finding a single element

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "prefer-array-find": "error"
  }
}
```
