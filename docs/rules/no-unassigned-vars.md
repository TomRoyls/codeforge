# no-unassigned-vars

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow variables that are read but never assigned.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-unassigned-vars": "error"
  }
}
```
