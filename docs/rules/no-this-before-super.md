# no-this-before-super

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | style |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow this/super before super() calling.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-this-before-super": "error"
  }
}
```
