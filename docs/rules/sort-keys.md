# sort-keys

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | style |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Enforce alphabetical sorting of object literal keys for better readability and consistency.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "sort-keys": "error"
  }
}
```
