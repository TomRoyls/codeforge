# prefer-string-template

| Property | Value |
|----------|-------|
| Category | style |
| Fixable | No |
| Recommended | No |
| Deprecated | No |

## Description

Suggests using template literals instead of string concatenation

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "prefer-string-template": "error"
  }
}
```
