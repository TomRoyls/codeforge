# no-alert

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow the use of alert, confirm, and prompt browser dialogs.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-alert": "error"
  }
}
```
