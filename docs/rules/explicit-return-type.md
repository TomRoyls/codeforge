# explicit-return-type

| Property | Value |
|----------|-------|
| Category | style |
| Fixable | No |
| Recommended | No |
| Deprecated | No |

## Description

Require explicit return types on functions

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "explicit-return-type": "error"
  }
}
```
