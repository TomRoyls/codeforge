# prefer-array-some

| Property | Value |
|----------|-------|
| Category | style |
| Fixable | No |
| Recommended | No |
| Deprecated | No |

## Description

Suggests using Array.prototype.some() instead of indexOf checks

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "prefer-array-some": "error"
  }
}
```
