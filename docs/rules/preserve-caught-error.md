# preserve-caught-error

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | style |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Require using caught error variables.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "preserve-caught-error": "error"
  }
}
```
