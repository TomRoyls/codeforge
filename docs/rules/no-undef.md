# no-undef

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow undeclared variables.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-undef": "error"
  }
}
```
