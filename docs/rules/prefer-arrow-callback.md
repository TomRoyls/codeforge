## Description

Enforce using arrow functions for callbacks

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "prefer-arrow-callback": "error"
  }
}
```

This rule is auto-fixable. Run `codeforge fix --rules prefer-arrow-callback` to apply fixes.
