# no-unsafe-negation

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow negating the left operand of relational operators.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-unsafe-negation": "error"
  }
}
```
