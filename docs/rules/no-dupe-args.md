# no-dupe-args

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | style |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow duplicate arguments in function definitions.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-dupe-args": "error"
  }
}
```
