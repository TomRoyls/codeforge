# no-dupe-keys

![Recommended](https://img.shields.io/badge/-recommended-blue)

| Property | Value |
|----------|-------|
| Category | patterns |
| Fixable | No |
| Recommended | Yes |
| Deprecated | No |

## Description

Disallow duplicate keys in object literals.

## How to Use

Enable this rule in your configuration:

```json
{
  "rules": {
    "no-dupe-keys": "error"
  }
}
```
